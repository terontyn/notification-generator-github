# Генератор уведомлений из Excel и Word

Скрипт создаёт отдельный `.docx` для каждой пары «договор (столбец F) + дата транша (столбец H)». Строки с одним договором и датой попадают в общую таблицу. Итог считается из сумм документов; рядом создаётся `report.txt`.

Это локальная программа: документы никуда не отправляются. **Проверяйте готовые уведомления перед использованием**, особенно суммы, номера, даты и оформление.

## Установка

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Подготовка входных файлов

Первая строка Excel содержит заголовки; программа читает **позиции столбцов**, а не их названия. Нужен `.xlsx` с девятью столбцами A–I:

| Столбец | Значение |
| --- | --- |
| A | Целый номер уведомления, одинаковый для всех строк одной группы |
| B | Номер УПД; числовые значения дополняются слева нулями до 6 знаков |
| C | Дата документа |
| D | Неотрицательная сумма с точностью до копейки |
| E | Номер спецификации, может быть пустым |
| F | Текст договора |
| G | Не используется |
| H | Дата выдачи транша |
| I | Дата оплаты |

Номера УПД длиннее 6 знаков остаются длинными. Если ведущие нули имеют смысл сверх дополнения до шести знаков, храните значение столбца B как **текст Excel**. Пустые УПД, суммы, даты и номера уведомлений вызывают ошибку.

В шаблоне `.docx` нужны **две таблицы**: первая для шапки, вторая с одной строкой заголовков и ровно шестью столбцами для данных. Поместите в обычный текст или ячейки таблиц следующие метки:

| Метка | Подстановка |
| --- | --- |
| `{{NOTIFICATION_NUMBER}}` | Номер из A |
| `{{NOTIFICATION_DATE}}` | Дата из H в виде `«15» декабря 2025 г.` |
| `{{CONTRACT_NUMBER}}` | Текст договора из F |

Пример шапки: `Исх. №{{NOTIFICATION_NUMBER}} от {{NOTIFICATION_DATE}}`. Метки можно разделять форматированием Word на фрагменты внутри одного абзаца; через границы разных абзацев они не заменяются. Строки после заголовка второй таблицы удаляются и заполняются заново. Подстановка действует в обычных абзацах и таблицах документа; колонтитулы и текстовые поля не обрабатываются.

## Запуск

```bash
python notification_generator.py data.xlsx template.docx notifications
```

Выходная папка по умолчанию — `notifications`. Программа откажется перезаписывать существующие уведомления: выбирайте новую папку для повторного запуска. Отчёт и выходные документы могут содержать чувствительные данные и игнорируются Git.

Для проверки без рабочих данных создайте полностью вымышленные входные файлы:

```bash
python examples/make_demo.py
python notification_generator.py examples/generated/data.xlsx examples/generated/template.docx examples/generated/output
python -m unittest discover -s tests -v
```

## Ограничения

- Исходный шаблон из архива содержал конкретный текст для поиска. Для этой версии замените такие фрагменты тремя метками, указанными выше.
- Проверяется структура второго блока таблиц, но стили, переносы страниц и юридическая корректность документа требуют просмотра в Word.
- Даты Excel должны распознаваться как даты; формулы должны иметь сохранённые вычисленные значения.
- Шаблоны с вложенными таблицами, текстовыми полями или метками в колонтитулах не поддерживаются.

## Публикация

В проекте только код и вымышленные примеры. Оригинальная рабочая таблица, документы, отчёты и вложенные архивы из источника намеренно исключены. Перед загрузкой своей версии проверьте `git status` и содержимое коммита. Лицензия не задана: владелец проекта выбирает её отдельно перед публичным распространением.
